// Digitalisierung des Urlaubsantrags für Auszubildende bei Grone


**Auszubildende
    - sich anmelden, daten ansehen
    - gewünschten Urlaubszeitraum auswählen
    - die Anzahl der Urlaubstage sehen, einen Antrag absenden und Status verfolgen
    - bisherigen Urlaubsanträge sehen, noch nicht bearbeiteten Antrag zurückziehen

**Ausbilder
    - urlaubsanträge anzeigen
    - prüfen, genehmigen, ablehnen, begründung hinterlegen
    - urlaubshistorie einsehen
    
**Administrator
    - zuordnen
    - rollen verwalten
    - alle Urlaubsanträge einsehen


## BUILD INFO
• Frontend: TypeScript, React
• Backend: Java Springboot - REST API
• Datenbank: SQL
